# Changelog

## 1.0.0 — 2026-10-08

First release, available on [Creator Extensions](https://extensions.lottiefiles.com/plugin/karthikeyan-ranasthala/openverse-sfx).

- Search Freesound and other Openverse audio sources.
- Filter by duration, license, intended use, and file format.
- Preview sounds with waveforms, seeking, volume, mute, and looping.
- Save favorite sounds for later in the same browser.
- Add audio at the playhead or scene start, with optional scene extension.
- View source and license details, with attribution kept on the audio layer.
- Support MP3, WAV, M4A, FLAC, and OGG files up to 20 MB.
