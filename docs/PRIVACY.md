# Data and privacy

Openverse SFX runs in LottieFiles Creator and has no plugin-operated server or built-in analytics. No Openverse account or API key is required.

## Searches and audio

Search terms and selected filters are sent to Openverse to find audio. Previewing or adding a sound requests audio from its original provider through the browser or Creator. Those services receive normal request information, including your IP address, and their own privacy policies apply.

## Saved sounds

Favorites are stored through Creator's plugin storage in the browser where you use the plugin, scoped to your Creator user and this plugin. They do not sync across devices. You can remove a favorite in the plugin. In the standalone development preview, favorites stay in memory for that session.

## Added audio and attribution

Adding audio changes the open Creator scene. The sound's title, creator, attribution, source/license links, and media link are kept as metadata on the added layer so you can review them later. Creator's own asset storage and platform policies also apply.

Openverse SFX is an independent community plugin. For questions, use the repository's [issue tracker](https://github.com/KarthikeyanRanasthala/creator-plugin-openverse-sfx/issues).
